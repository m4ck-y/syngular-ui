# Glassmorphism

## Overview
Glassmorphism UI library with translucent frosted glass aesthetics.

## Files
- [components/](components/) - Glassmorphism component library
- [glass-theme.css](glass-theme.css) - Global glass theme
- [index.ts](index.ts) - Module exports

## Purpose
Provides glassmorphism UI components featuring translucent frosted glass aesthetics with blur effects and subtle shadows for modern interface design.

## Exports
- GlassButton - Glass-effect button
- GlassInput - Text input field
- GlassSelect - Dropdown select
- GlassCheckbox - Checkbox component
- GlassRadio - Radio button
- GlassTable - Data table
- GlassModal - Modal dialog
- GlassCard - Card container
- GlassToggle - Toggle switch
- GlassSlider - Slider control
- GlassBadge - Status badge
- GlassProgressBar - Progress bar
- GlassChart - Chart component
- GlassNavigation - Navigation
- GlassIndicator - Status indicator
- GlassIconCard - Icon card
- GlassCircularProgress - Circular progress
- GlassMediaPlayer - Media player
- GlassLoginCard - Login card
