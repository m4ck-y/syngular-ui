# Source Code

## Overview
Multi-style UI component library with futuristic design systems.

## Files
- [App.tsx](App.tsx) - Main application component
- [App.css](App.css) - Application styles
- [index.css](index.css) - Global styles
- [main.tsx](main.tsx) - Application entry point
- [assets/](assets/) - Static assets
- [fui/](fui/) - Futuristic Industrial UI components
- [glassmorphism/](glassmorphism/) - Glassmorphism style components
- [neumorphism/](neumorphism/) - Neumorphism style components
- [pages/](pages/) - Page components

## Purpose
Contains a comprehensive UI component library with multiple design systems: FUI HUD (futuristic industrial), FUI Glass (glassmorphism variant), Glassmorphism, and Neumorphism styles for building modern and futuristic interfaces.
