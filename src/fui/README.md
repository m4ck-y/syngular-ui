# FUI (Futuristic Industrial UI)

## Overview
Futuristic Industrial UI library containing multiple design systems for sci-fi interfaces.

## Files
- [hud/](hud/) - HUD-style components
- [glass/](glass/) - Glassmorphism FUI components

## Purpose
Provides futuristic UI component libraries including HUD-style industrial components and glass-effect variants for building sci-fi interfaces with consistent design language.
