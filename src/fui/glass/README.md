# FUI Glass

## Overview
Futuristic UI with glassmorphism effects combining HUD aesthetics and translucency.

## Files
- [components/](components/) - FUI Glass component library
- [fui-glass-theme.css](fui-glass-theme.css) - Global FUI Glass theme
- [index.ts](index.ts) - Module exports

## Purpose
Provides futuristic glass-effect UI components combining industrial HUD aesthetics with glassmorphism translucency for modern sci-fi interfaces.

## Exports
- FuiGlassButton - Glass button
- FuiGlassInput - Glass input
- FuiGlassCard - Glass card
- FuiGlassTable - Glass table
- FuiGlassSelect - Glass select
- FuiGlassCheckbox - Glass checkbox
- FuiGlassRadio - Glass radio
- FuiGlassProgress - Progress indicator
- FuiGlassBadge - Badge component
- FuiGlassTooltip - Tooltip
- FuiGlassToggle - Toggle switch
- FuiGlassSlider - Slider
- FuiGlassAccordion - Accordion
- FuiGlassToast - Toast notification
- FuiGlassSpinner - Loading spinner
