# FUI HUD

## Overview
Futuristic Industrial UI library with HUD-style components for sci-fi interfaces.

## Files
- [components/](components/) - HUD component library
- [fui-theme.css](fui-theme.css) - Global FUI theme styles
- [index.ts](index.ts) - Module exports

## Purpose
Provides HUD-style futuristic UI components with industrial aesthetic, including buttons, cards, forms, tables, and decorative elements for sci-fi interface design.

## Exports
- FuiButton - Futuristic button
- FuiCard, FuiHeaderBar - Card components
- FuiBadge, FuiChip, FuiDataPill, FuiStatusIndicator - Badge variants
- FuiToggle, FuiSlider, FuiProgressBar - Control components
- FuiSelect, FuiCheckbox, FuiCheckboxGroup, FuiRadio, FuiRadioGroup, FuiFileUpload - Form components
- FuiTable, FuiInfoRow - Table components
- FuiInput - Input field
- AIModal - AI modal
- FuiTooltip - Tooltip
- FuiCornerBrackets - Decorative brackets
- FuiBackgrounds, FuiGridPattern - Background patterns
- FuiDecoratedCard - Decorated card
- FuiPulsingDot, FuiPulsingDots - Loading dots
- FuiNetworkTraffic - Traffic visualization
- FuiTypography - Typography
- FuiCryptoTicker - Crypto ticker
- FuiInitiateButton - CTA button
- FuiParticles - Particle effects
- FuiGlitch - Glitch effect
- FuiTypewriter - Typewriter effect
