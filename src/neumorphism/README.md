# Neumorphism

## Overview
Neumorphism UI library with soft 3D extruded appearance.

## Files
- [components/](components/) - Neumorphism component library
- [neumorphic-theme.css](neumorphic-theme.css) - Global neumorphic theme
- [index.ts](index.ts) - Module exports

## Purpose
Provides neumorphic UI components featuring soft 3D extruded appearance with subtle shadows creating a tactile, modern interface aesthetic.

## Exports
- NeumorphicButton - Soft 3D button
- NeumorphicCard - Card container
- NeumorphicInput - Input field
- NeumorphicCheckbox - Checkbox
- NeumorphicRadio - Radio button
- NeumorphicSelect - Dropdown select
- NeumorphicTable - Data table
