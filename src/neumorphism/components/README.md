# Neumorphism Components

## Overview
Neumorphism style UI components with soft 3D extruded appearance.

- [NeumorphicButton.module.css](NeumorphicButton.module.css) - Button styles
- [NeumorphicCard.tsx](NeumorphicCard.tsx) - Extruded card container
- [NeumorphicCard.module.css](NeumorphicCard.module.css) - Card styles
- [NeumorphicCheckbox.tsx](NeumorphicCheckbox.tsx) - Soft checkbox

Provides neumorphic UI components featuring soft 3D extruded appearance with subtle shadows creating a tactile, modern interface aesthetic.
